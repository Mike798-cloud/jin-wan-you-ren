# 《今晚有人进过我家》

二维写实场景恐怖悬疑网页游戏。玩家是普通独居租客，在一次加班回家后发现家中物品被人动过。

## 玩法
- 隐藏热点探索：热点不高亮、鼠标经过不变光标。
- 5个主要空间：玄关/厨房、客厅、卧室、卫生间、七楼走廊。
- 记忆验证、环境异常、人物信息交叉。
- 三级提示、自动本地存档、平板/电脑响应式布局。
- 3个普通结局 + 1个隐藏结局。
- 完整免费游玩 + 结局后自愿支持入口（上线前自行配置收款信息）。

## 部署
将 release 目录内全部内容放到 GitHub Pages / Cloudflare Pages / 任意静态服务器根目录即可。
直接双击 index.html 也能运行，但推荐通过静态服务器访问。

## 构建
Windows：双击 `build_release.bat`。脚本检查 JS 语法并生成 `release` 文件夹和 ZIP。
