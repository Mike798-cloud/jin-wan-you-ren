# 《今晚有人进过我家》

二维写实场景恐怖悬疑网页游戏。玩家是普通独居租客，在一次加班回家后发现家中出现一连串无法用“记错了”解释的细节。

## 本版内容

- 首次完整主线目标时长约 40–60 分钟（取决于探索与是否使用提示）。
- 5 个主要空间：玄关/厨房、客厅、卧室、卫生间、七楼走廊。
- 11 个调查阶段：回家、记忆核对、房东交叉询问、二次排查、时间线、门链、七楼调查、入口路径推理、维修夹层分层搜证、人物身份交叉、最终证据边界判断。
- 4 组非纯点击谜题：记忆证据边界、时间线重建、入口路径推理、人物身份交叉。
- 隐藏热点仍不高亮，鼠标经过不改变光标；三级提示按“阶段 + 当前页面”独立记录并可回看。
- 浏览器实时合成住宅底噪、冰箱低鸣、管线/水滴、邻里闷响、金属声、电梯提示音和手机震动，不依赖额外音频文件。
- 自动本地存档，兼容旧版 v1 存档迁移。
- 3 个普通结局 + 1 个隐藏结局；通关后解锁结局档案和二周目快速复盘。

## 部署

可直接将项目根目录部署到 GitHub Pages / Cloudflare Pages / 任意静态服务器。直接双击 `index.html` 也能运行，但推荐静态服务器。

## Windows 构建

双击 `build_release.bat`：

1. 使用 `node --check game.js` 与 `node --check paywall.js` 检查 JavaScript 语法；
2. 生成 `release` 文件夹；
3. 复制网页源码、付款系统、收款码、资产说明和图片资源；
4. 生成 `jin-wan-you-ren-release.zip`。

如果系统没有安装 Node.js，脚本会明确提示，不会生成一个未校验的发行包。


## 视觉与氛围升级

- 全部5个夜景空间 + 1张早晨对照图已统一为同一套普通租住公寓的视觉语言。
- 优化了画面单张质量、剧情适配度与空间连续性，减少“不同房子拼接”的割裂感。
- 环境音改为更丰富的浏览器实时合成：冰箱低鸣、远处电梯提示音、邻里闷响、金属轻碰、水滴/管线声等，并根据房间触发不同氛围细节。


## 细节打磨

- 常驻目标改为“方向提示”而不是直接报出具体证据位置，三级提示继续承担兜底作用。
- 关键物证保持不高亮，但点击区域与新场景重新对齐，避免“看得见却点不到”或误触其他物件。
- 环境声改为随机间隔触发：前半段更稀疏，七楼调查后略微加密，不再固定每 17 秒机械出现。
- 不同房间有不同的声音倾向，并加入进入房间后的轻微情境声；不会用突然大音量制造跳吓。
- 当前 6 张核心场景均为本项目重新制作的统一场景资产，旧版第三方摄影授权条目已从 `LICENSES.md` 移除。


## 自愿支持系统

- 付款交互沿用《松涛粮站》的纯前端自愿支持流程，使用 `paywall.js`、`paywall.css` 与 `paycode.png`。
- “支持作者 1元”入口位于顶部“提示”按钮旁。
- 玩家首次真正进入可操作游戏页面后自动展示一次；关闭后不会在同一浏览器重复自动打扰。
- “已完成支持”会把记录写入浏览器本地存储；重置案件不会清除支持记录。
- 自愿支持不会影响剧情、三级提示、隐藏结局、二周目或存档。
