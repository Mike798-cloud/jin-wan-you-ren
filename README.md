# 《今晚有人进过我家》

二维写实场景恐怖悬疑网页游戏。玩家是普通独居租客，在一次加班回家后发现家中出现一连串无法用“记错了”解释的细节。

## 本版内容

- 首次完整主线目标时长约 40–60 分钟（取决于探索与是否使用提示）。
- 5 个主要空间：玄关/厨房、客厅、卧室、卫生间、七楼走廊。
- 11 个调查阶段：回家、记忆核对、房东交叉询问、二次排查、时间线、门链、七楼调查、入口路径推理、维修夹层分层搜证、人物身份交叉、最终证据边界判断。
- 4 组非纯点击谜题：记忆证据边界、时间线重建、入口路径推理、人物身份交叉。
- 隐藏热点仍不高亮，鼠标经过不改变光标；三级提示按“阶段 + 当前页面”独立记录并可回看。
- 浏览器实时合成低频环境声、管线声、金属声和手机震动，不依赖额外音频文件。
- 自动本地存档，兼容旧版 v1 存档迁移。
- 3 个普通结局 + 1 个隐藏结局；通关后解锁结局档案和二周目快速复盘。

## 部署

可直接将项目根目录部署到 GitHub Pages / Cloudflare Pages / 任意静态服务器。直接双击 `index.html` 也能运行，但推荐静态服务器。

## Windows 构建

双击 `build_release.bat`：

1. 使用 `node --check game.js` 检查 JavaScript 语法；
2. 生成 `release` 文件夹；
3. 复制网页源码、授权说明和图片资源；
4. 生成 `jin-wan-you-ren-release.zip`。

如果系统没有安装 Node.js，脚本会明确提示，不会生成一个未校验的发行包。
